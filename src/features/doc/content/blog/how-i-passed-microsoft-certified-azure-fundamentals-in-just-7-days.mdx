Last month, I passed the Microsoft Certified: Azure Fundamentals exam. Two weeks before that, I had passed the AWS Cloud Practitioner exam.

After finishing AWS, I wanted to understand how Azure works. I was still in a learning mood, so I decided to take the Azure exam as well. I gave myself 7 days to prepare.

I studied for 1 hour each day. I kept my plan simple and focused.

These are the only two resources I used:

- **Pete Zerger’s Azure Fundamentals Exam Cram on YouTube**: It was short and clear.
- **Andrew Brown’s course and practice tests on ExamPro**: They helped me understand the exam format and topics.

On the exam day, I received 31 questions. Around 10 of them were True or False. These were the most difficult, because they tested small details. The rest of the questions were easier and focused on Azure services, pricing, and support plans.

Since I had already studied AWS, some cloud concepts were familiar. This made learning Azure faster. Still, I had to learn Microsoft’s terms and structure, which are different from AWS.

## Lessons learned

- Use only one or two good resources. Too many can waste time.
- Practice tests help you learn and also prepare you for the real exam style.
- One hour each day is enough if you stay consistent.
- Focus on the basic topics. You do not need to go deep into technical areas.

Passing this exam gave me more confidence in my cloud learning journey. I was happy with how simple and focused the process was.

If you are planning to take the Azure Fundamentals exam, keep it simple. Study clearly, stay consistent, and use the right materials.

That is how I passed the Microsoft Certified: Azure Fundamentals in just 7 days.
